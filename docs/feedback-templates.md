# AutoTicket フィードバックテンプレート

このチャンネルに気づいたことを投稿してください。
下の3種類からあてはまるものをコピーして、**太字の行を書き換えて**送ってください。
「わからない」「特になし」の記入でも大丈夫です。

---

## 🐛 バグ報告（動作がおかしい・エラーが出る）

```
【バグ報告】

■ どこで起きましたか？
→ 例）ウィジェット／タスク一覧／ガント／インポート など

■ 何が起きましたか？
→ 例）「起票」ボタンを押すと「接続失敗」と表示されてタスクが登録できない

■ どう操作したら起きましたか？
→ 例）
　1. Ctrl+Shift+Space でウィジェットを開く
　2. タイトルを入力して「起票」ボタンをクリック
　3. 赤いエラーメッセージが表示される

■ 本来どうなってほしかったですか？
→ 例）タスクが登録されてウィンドウが閉じてほしかった

■ どのくらいの頻度で起きますか？
→ 例）毎回／たまに（2〜3回に1回）／1回だけ

■ スクリーンショット（あれば貼り付けてください）
→
```

## 💡 機能改善（使いにくい・こうしてほしい）

```
【機能改善】

■ どの画面・機能についてですか？
→ 例）タスク一覧のフィルタ／ガントのバー操作／完了ボタン など

■ 今、どんなことが不便ですか？
→ 例）フィルタ（担当者・ステータス）を設定しても、別の画面に移動するたびにリセットされる

■ どうなってほしいですか？
→ 例）画面を移動してもフィルタ設定が維持されてほしい

■ どのくらい困っていますか？
→ 例）毎日発生する／週に数回／たまに
```

---

## ✨ 機能追加（今はない機能がほしい）

```
【機能追加リクエスト】

■ どんな場面で使いたいですか？
→ 例）会議が終わったあと、議事録のテキストを貼り付けるだけでタスクをまとめて起票できると便利

■ 今はどうやって対処していますか？
→ 例）議事録を見ながら1件ずつ手動で起票している（毎回10分以上かかる）

■ どんな動きをイメージしていますか？
→ 例）テキストを貼り付けて「解析」ボタンを押すとタスク候補が一覧表示され、確認してから一括起票できる

■ 重要度（どちらかを残してください）
→ 高（これがあれば業務が大きく改善する）／中（あるとかなり便利）／低（あれば嬉しい程度）
```
