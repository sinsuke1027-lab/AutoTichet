# Ollama セットアップガイド

**対象**: AutoTicket の「AI で起票する」機能を使いたいメンバー  
**所要時間**: 約10〜20分（モデルのダウンロード時間を含む）  
**必要なもの**: インターネット接続・空き容量 2GB 以上

> ℹ️ **Ollama がなくても AutoTicket は使えます。**  
> 「手動で起票する」を使えば AI なしでタスク登録ができます。  
> AI 機能が必要な場合のみこのガイドを進めてください。

---

## ステップ 1: Ollama をダウンロードする

1. ブラウザで以下のURLを開く

   ```
   https://ollama.com/download
   ```

2. **「Download for Windows」** ボタンをクリック
3. `OllamaSetup.exe` がダウンロードされる（約100MB）

---

## ステップ 2: Ollama をインストールする

1. ダウンロードした `OllamaSetup.exe` を**ダブルクリック**
2. Windowsのセキュリティ警告が出た場合は「実行」をクリック
3. インストールが自動で進む（操作不要）
4. 完了するとタスクバー右下に Ollama のアイコン（🦙）が表示される

> ✅ アイコンが表示されれば Ollama のインストール成功です。

---

## ステップ 3: AIモデルをダウンロードする

ここだけ「コマンドプロンプト」という黒い画面を使います。  
以下の手順をそのままなぞってください。

### コマンドプロンプトの開き方

1. キーボードの **`Windowsキー`** を押す（田のマークのキー）
2. **`cmd`** と入力する
3. 「コマンドプロンプト」が表示されたら **クリック** して開く
4. 黒い画面が開いたら成功

### モデルをダウンロードするコマンドを実行する

黒い画面に以下の文字を**コピー&ペースト**して **`Enter`** キーを押します。

```
ollama pull qwen2.5:1.5b
```

> **コピー&ペーストの方法:**  
> 上の文字を選択 → `Ctrl+C` でコピー → 黒い画面を右クリック → 「貼り付け」 → `Enter`

ダウンロードが始まります（約1GB・数分〜10分程度）。  
以下のような表示が出たら完了です：

```
success
```

> ⚠️ ダウンロード中は画面を閉じないでください。  
> 途中で止まった場合は、同じコマンドをもう一度実行すると再開します。

---

## ステップ 4: AutoTicket ウィジェットで設定する

1. AutoTicket ウィジェット（トレイアイコン）を **右クリック** → 「設定」を開く
2. 「Ollama テキストモデル」ドロップダウンを開く
3. **`qwen2.5:1.5b`** を選択する
4. 「保存」をクリック

> リストが空の場合は **🔄 ボタン** をクリックしてモデル一覧を再取得してください。

---

## 動作確認

1. `Ctrl + Shift + Space` でタスク入力ウィンドウを開く
2. テキスト欄に「来週月曜に山田さんへ報告書を提出する」などと入力
3. **「AI で起票する」** ボタンをクリック
4. タイトル・期日などが自動で入力されれば成功

---

## トラブルシューティング

| 症状 | 対処方法 |
|------|---------|
| 「AIで起票する」ボタンが灰色で押せない | Ollamaが起動していない。タスクバー右下の🦙アイコンを確認。なければ「スタートメニュー」→「Ollama」を起動 |
| ダウンロードが途中で止まった | 同じコマンドをもう一度実行（自動で続きから再開） |
| モデル名がリストに出ない | 設定画面の🔄ボタンをクリック。それでも出ない場合はステップ3からやり直し |
| AIの解析が遅い | PCの性能によっては時間がかかります。スペックが低いPCでは手動起票をお勧めします |
| コマンドが「認識されていません」と出る | Ollamaのインストールが完了していません。ステップ2からやり直し |

---

## PC を再起動したあとの確認

Ollama は PC 起動時に自動で起動します。  
タスクバー右下に 🦙 アイコンがあれば、何も操作しなくても AI 機能が使えます。

アイコンがない場合は「スタートメニュー」→「Ollama」をクリックして起動してください。
