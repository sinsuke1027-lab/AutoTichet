## 1. ログイン

アプリにアクセスすると、ログイン画面が表示されます。

- 会社の Microsoft アカウント（Entra ID）でサインインしてください
- 管理者から案内された URL を Chrome または Edge（最新版）で開いてください

> **注意:** 初回アクセス時にバックエンドのウォームアップで 30〜60 秒かかる場合があります。しばらく待ってからリロードしてください。

---

## 2. ダッシュボード

ログイン後に最初に表示される画面です。自分に関係するタスクの状況を一覧で把握できます。

### 表示内容

| カード | 説明 |
|-------|------|
| 総タスク数 | 自分が担当するタスクの合計 |
| 進行中 | ステータスが「進行中」のタスク数 |
| 完了率 | 完了タスク ÷ 総タスク数（%） |
| 期限超過 | 期限を過ぎた未完了タスク数 |

- **今日やること** — 今日が期限のタスク一覧
- **期限超過タスク** — 期限切れタスクの一覧
- **完了トレンド** — 過去 30 日間の完了数グラフ
- **ワークロード** — チームメンバーの稼働状況（リーダー・管理者に表示）

---

## 3. タスク一覧

サイドバーの「タスク一覧」からアクセスします。

### タスクの作成

1. 右上の「**＋ タスク追加**」ボタンをクリック
2. タイトル・担当者・期限・優先度を入力して「作成」

### 絞り込み・検索

- 上部の検索ボックスにキーワードを入力すると、タイトル・説明を全文検索します
- 「担当者」「ステータス」「優先度」でフィルターできます（リーダー以上は全員の担当者を選択可）

### 一括操作

タスク左のチェックボックスを選択すると、複数タスクを一括で「ステータス変更」「担当者変更」できます。

### CSV エクスポート

一覧右上の「エクスポート」ボタンから、表示中のタスクを CSV でダウンロードできます。

---

## 4. タスク詳細

タスク一覧のタイトルをクリックすると詳細パネルが開きます。

### 詳細タブ

| 項目 | 説明 |
|------|------|
| ステータス | 未着手 / 進行中 / 完了 / キャンセル |
| 優先度 | 低 / 中 / 高 / 緊急 |
| 担当者 | メイン担当者（サブ担当者も追加可） |
| 期限 / 開始日 | カレンダーから選択 |
| 公開範囲 | 自分のみ / チーム / 全体 |
| タグ | 部門タグで分類 |
| 説明 | タスクの詳細・背景 |
| 繰り返し | 毎日 / 毎週 / 毎月の繰り返しタスク設定 |

### コメントタブ

- チームメンバーへのメンション（@名前）が使えます
- SharePoint リンクを貼り付けると関連資料としてリンク表示されます

### 工数タブ

- 「予定工数」「実績工数」を時間単位で記録します
- 過去の記録は履歴として残ります
- **AI 目標工数推定** — 類似タスクの実績から AI が推奨工数を提案します

### サブタスクタブ

- サブタスクを追加して親タスクの進捗を細かく管理できます
- **AI サブタスク生成** — タスクタイトルと説明をもとに AI がサブタスク候補を提案します

### AI チェック（要件チェックタブ）

「AI チェック」ボタンを押すと、タスクの記載内容を AI が確認し、以下の不足を指摘します：

- 期限が設定されていない
- 担当者が未設定
- 説明が不十分

指摘に応じて AI が改善案も提示します。

## 5. プロジェクト管理

サイドバーの「プロジェクト」からアクセスします。

### プロジェクトの作成

「＋ プロジェクト作成」から名前・説明を入力して作成します。

### セクション管理

プロジェクト内のタスクをフェーズや担当チーム単位で「セクション」に分けられます。

- セクションの追加・並び替え・削除が可能です
- タスクをドラッグ＆ドロップでセクション間を移動できます

### マイルストーン

プロジェクトの重要な節目（リリース日・締切など）をマイルストーンとして登録すると、ガントチャートに表示されます。

---

## 6. カンバン

サイドバーの「カンバン」からアクセスします。

4 列（未着手 / 進行中 / 完了 / キャンセル）のボードでタスクを管理します。

- カードをドラッグ＆ドロップして列を移動すると、ステータスが自動更新されます
- プロジェクト・担当者でフィルターできます

---

## 7. カレンダー

サイドバーの「カレンダー」からアクセスします。

- 月間ビューで期限日ごとのタスクを表示します
- タスクをクリックすると詳細パネルが開きます

---

## 8. ガントチャート

サイドバーの「ガント」からアクセスします。

プロジェクトを選択すると、タスクの開始日〜期限をバーで表示します。

### 依存関係

タスクバー間をドラッグして「このタスクが終わったら次のタスクを始める」という前後関係（依存関係）を設定できます。

### マイルストーン

プロジェクトに設定したマイルストーンがダイヤモンドマークで表示されます。

---

## 9. スケジュール（1日ビュー）

サイドバーの「スケジュール」からアクセスします。

「今日やること」を時間軸で管理するビューです。

- 「**未配置のタスク**」列から今日対応するタスクをドラッグ＆ドロップで時間帯に配置できます
- 週単位で切り替えて今週の予定を確認できます

---

## 10. ワークロード

サイドバーの「ワークロード」からアクセスします。

チームメンバーの稼働時間と余力を可視化します。

| 表示 | 説明 |
|------|------|
| 予定工数 | 各メンバーの担当タスクの見積工数合計 |
| 稼働可能時間 | メンバーごとの 1 日あたり稼働時間設定値 |
| 超過 | 予定工数が稼働可能時間を超えているメンバーをオレンジで表示 |

- **ロール別スコープ:** 一般メンバーは自分のみ、リーダーは担当チームのみ、管理者は全員を表示します

---

## 11. テンプレート

サイドバーの「テンプレート」からアクセスします。

よく使うタスクパターン（タイトル・サブタスク・優先度・工数など）をテンプレートとして保存し、ワンクリックで新規タスクを作成できます。

### テンプレートの作成

1. 「＋ テンプレート作成」をクリック
2. タイトル・説明・デフォルトの優先度・サブタスクを設定して保存

### テンプレートからタスクを作成

テンプレートカードの「適用」ボタンをクリックし、基準日・プロジェクト・担当者を選択すると即座にタスクが作成されます。

---

## 12. データインポート

サイドバーの「データインポート」からアクセスします（管理者・リーダー向け）。

Asana などからエクスポートした Excel ファイル（.xlsx）を取り込み、タスクを一括登録できます。

### 手順

1. 「ファイルを選択」から xlsx ファイルをアップロード
2. プレビュー画面でインポート内容を確認
3. 「インポート実行」で一括登録

---

## 13. マイページ

サイドバーの「マイページ」からアクセスします。

### 表示内容

- 自分が担当するタスクのサマリー（今日・今週・期限超過）
- 今週の工数実績グラフ
- 停滞タスク（長期間更新がないタスク）の一覧

### 引き継ぎドキュメント生成

「引き継ぎ書を生成」ボタンを押すと、自分が担当する進行中タスクをまとめた引き継ぎ書を AI が Markdown 形式で自動生成します。

---

## 14. グローバル検索（Cmd + K）

キーボードショートカット **Cmd + K**（Mac）または **Ctrl + K**（Windows）でコマンドパレット風の検索ボックスが開きます。

- タスクタイトル・説明・コメント本文を横断検索します
- 検索結果をクリックすると該当タスクの詳細が開きます

---

## 15. 通知（アラート）

ヘッダー右上のベルアイコンに、未読アラートの件数がバッジ表示されます。

### アラートの種類

| 種類 | 内容 |
|------|------|
| ワークロード超過 | 予定工数が稼働可能時間を超えた日 |
| 期限超過 | 期限を過ぎた担当タスク |
| 停滞タスク | 長期間（デフォルト 14 日）更新がないタスク |
| リスクタスク | 期限まで余裕が少ない高優先度タスク |

ベルアイコンをクリックするとアラート一覧が表示されます。

## 16. 管理設定（管理者のみ）

サイドバーの「管理設定」は **admin ロールのユーザーのみ** 表示されます。

### ユーザー管理タブ

| 操作 | 説明 |
|------|------|
| ユーザー追加 | 新しいメンバーをシステムに登録します |
| 編集 | 表示名・メール・ロール・部門タグ・稼働時間を変更します |
| 削除 | メンバーをシステムから削除します |

**ロールの種類:**

| ロール | 権限 |
|--------|------|
| member | 自分のタスクを管理。チームタスクは閲覧のみ |
| leader | 担当チームのタスクを管理・ワークロード確認 |
| admin | 全機能 + 管理設定 |

### 組織設定タブ

社内で使用する**部門タグ**を管理します。

- タグを追加・編集・削除できます
- ユーザーに部門タグを割り当てることで、ワークロードのスコープ（どのチームを見るか）が決まります

### アラート設定タブ

アラートの閾値を組織全体で設定します。

| 設定項目 | 説明 |
|---------|------|
| 停滞タスク検知日数 | 何日更新がなければ「停滞」と判定するか |
| ワークロード超過しきい値 | 稼働率何 % 超で「超過」と判定するか |

## よくある質問

**Q. 画面が最初に表示されるまで時間がかかります**  
A. バックエンドサーバーが省電力モードから復帰中です。30〜60 秒ほどお待ちいただき、リロードしてください。

**Q. タスクを削除したい**  
A. タスク詳細の「…」メニュー（右上）から削除できます。

**Q. 自分のタスクしか見えません**  
A. `member` ロールでは自分のタスクのみ表示されます。チーム全体を見たい場合は管理者にロール変更を依頼してください。

**Q. 部門タグが選択肢に出ません**  
A. 管理者に部門タグの追加を依頼してください（管理設定 → 組織設定）。

**Q. AI 機能が動きません**  
A. AI 機能は Gemini API を使用しています。管理者にサーバー状態を確認してもらってください。
