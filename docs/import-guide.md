# タスク移管ガイド — 他システムから AutoTicket へ

**対象**: 既存システム（Asana・Excel など）のタスクを AutoTicket に移したいメンバー  
**所要時間**: テンプレート記入 30分〜 / アップロード操作 2〜3分

---

## 1. このガイドの目的

AutoTicket には、Excel ファイル（.xlsx）を使って**タスクを一括で取り込む**機能があります。  
Asana・Excel・その他ツールで管理していたタスクを、このガイドの手順に沿って AutoTicket へ移行できます。

---

## 2. インポートテンプレートの場所・受け取り方

担当者から以下のファイルを受け取ってください。

```
インポートテンプレート.xlsx
```

このファイルを Excel で開き、タスク情報を入力していきます。  
ファイルが手元にない場合は AutoTicket 管理者に依頼してください。

> ✅ Asana をお使いの方は、テンプレートを使わずに Asana から直接エクスポートしたファイルをそのまま使えます。→ **4. よくあるシステムからの移行手順** を参照

## 4. よくあるシステムからの移行手順

### Asana から移行する場合

Asana からエクスポートしたファイルをそのまま使えます（列名の変換不要）。

1. Asana を開き、移行したいプロジェクトを開く
2. 右上の **「…」（その他）** メニュー → **「エクスポート/印刷」** → **「CSV」または「Excel」** を選択
3. ダウンロードされた `.xlsx` ファイルをそのまま使用する

> Asana のエクスポートファイルは英語列名（Name, Assignee, Due Date など）ですが、AutoTicket が自動で読み取ります。

### Excel・その他ツールから移行する場合

1. 担当者から受け取った **インポートテンプレート.xlsx** を開く
2. 2行目以降に、移行したいタスクを1行ずつ入力する
3. 1行目のヘッダー（列名）は変更しない
4. 入力が終わったら上書き保存する（`.xlsx` 形式のまま）

### スプレッドシート（Google スプレッドシートなど）から移行する場合

1. Google スプレッドシートで対象シートを開く
2. メニュー **「ファイル」→「ダウンロード」→「Microsoft Excel（.xlsx）」** を選択
3. ダウンロードされた `.xlsx` ファイルを使用する

## 5. Web アプリへのアップロード手順

### 手順 1: データインポートページを開く

1. ブラウザで以下のURLを開く（ログイン済みであること）

   ```
   https://auto-tichet.vercel.app/import
   ```

2. 「Asana データインポート」という画面が開く
3. **「1 ファイル選択」** のステップが表示されていることを確認する

### 手順 2: ファイルをアップロードする

**方法A: クリックして選択**
1. 画面中央の **「.xlsx ファイルをドロップするかクリックして選択」** エリアをクリック
2. ファイル選択ダイアログが開く
3. 準備した `.xlsx` ファイルを選んで「開く」をクリック

**方法B: ドラッグ＆ドロップ**
1. エクスプローラー（フォルダ）でファイルを表示する
2. ファイルをドラッグして、ブラウザの点線エリアに重ねて離す

ファイル名が表示されたら選択成功です。

### 手順 3: プレビューを確認する

1. **「プレビューを取得」** ボタンをクリック
2. 画面が **「2 プレビュー確認」** に切り替わる
3. 以下の情報を確認する

   | 確認項目 | 内容 |
   |---------|------|
   | タスク合計 | 取り込まれるタスク数。意図した件数か確認する |
   | セクション一覧 | セクション名と各件数 |
   | 警告（黄色い枠） | 担当者が未登録の場合などに表示される |

> ⚠️ **警告について**: 担当者のメールアドレスがシステムに未登録の場合「担当者は空になります」と表示されます。タスク自体は取り込まれますが、担当者未設定になります。後から手動で設定できます。

### 手順 4: インポートを実行する

1. 内容を確認したら **「インポート実行」** ボタンをクリック
2. 完了すると **「3 完了」** ステップに切り替わる
3. タスク一覧ページで取り込んだタスクが表示されることを確認する

## 6. 注意事項

### 必須列について
- **タイトル**列のみ必須です。他の列は空欄でもインポートできます。
- タイトルが空の行はスキップされます（エラーにはなりません）。

### 担当者の指定について
- 担当者列には、システムに登録されている**メールアドレス**を入力してください。
- 名前（例:「山田 花子」）では認識されません。
- 登録済みのメールアドレスが分からない場合は AutoTicket 管理者に確認してください。
- 未登録のアドレスを入力した場合、担当者なしでタスクが登録されます（後から設定可能）。

### 日付形式について
- `2026/07/15` または `2026-07-15` の形式で入力してください。
- `7/15` や `令和8年7月15日` などの形式は読み取れません。

### 重複インポートについて
- 同じファイルを2回アップロードすると、タスクが2重に登録されます。
- 誤って重複した場合は管理者に削除を依頼してください。

### ファイル形式について
- `.xlsx`（Excel形式）のみ対応しています。
- `.csv` や `.xls`（旧 Excel形式）は使用できません。
- Google スプレッドシートの場合は必ず Excel 形式でダウンロードしてください。

## 7. よくある質問（FAQ）

**Q. タスクが多すぎて1ファイルに収まらない場合は？**  
A. ファイルを複数に分けて、それぞれアップロードしてください。プロジェクト（セクション）ごとに分けると管理しやすいです。

**Q. 取り込んだタスクを後から修正できますか？**  
A. はい。Web アプリのタスク一覧からタスクをクリックして、タイトル・担当者・期限などを編集できます。

**Q. 取り込んだタスクをまとめて削除したい場合は？**  
A. タスク一覧でチェックボックスを使って複数選択し、一括操作で削除できます。大量削除の場合は管理者に依頼してください。

**Q. Asana のサブタスクも取り込めますか？**  
A. はい。Asana エクスポートファイルにサブタスクが含まれていれば、自動で親子関係が反映されます。

**Q. プレビューで件数がおかしい場合は？**  
A. キャンセルして Excel ファイルを確認してください。タイトルが空の行はカウントされません。また、ヘッダー行（1行目）がデータと誤認識される場合があります。

**Q. インポート後にタスクが表示されない場合は？**  
A. ブラウザを更新（F5キー）してみてください。それでも表示されない場合は管理者に連絡してください。
