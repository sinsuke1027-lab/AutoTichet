# AutoTicket ウィジェット 配布・運用ガイド

**対象**: チームへ `.exe` を配布する担当者  
**最終更新**: 2026-06-12

---

## 1. 配布物の場所と構成

PyInstaller でビルドすると `dist\AutoTicket\` フォルダが生成される。  
**このフォルダ全体** を共有フォルダにコピーして配布する。

```
dist\AutoTicket\
    AutoTicket.exe        ← メンバーがダブルクリックするファイル（約28 MB）
    _internal\            ← 依存ライブラリ群（削除・移動禁止）
```

> **注意**: `AutoTicket.exe` 単体では動作しない。`_internal\` フォルダと同じ場所に置く必要がある。

---

## 2. 初回配布手順（担当者作業）

```
1. ビルド済みの dist\AutoTicket\ フォルダを社内共有フォルダにコピーする
   例: \\server\tools\AutoTicket\

2. メンバーに以下を案内する:
   - 共有フォルダの AutoTicket.exe をダブルクリックするだけで起動できる
   - 初回のみセットアップウィザードが開く（所要時間: 1〜2分）
```

---

## 3. メンバー PC での起動方法

### 初回起動（セットアップウィザード）

`AutoTicket.exe` をダブルクリックすると 3 ステップのウィザードが開く。

| ステップ | 内容 |
|---------|------|
| Step 1 | バックエンド URL を入力 → 「接続テスト」で確認 |
| Step 2 | 自分の名前をドロップダウンから選択 |
| Step 3 | 設定を確認して「起動する」をクリック |

- **× ボタンで閉じるとアプリが終了する**（未完了のまま常駐しない仕様）
- 2回目以降はウィザードをスキップして直接起動する

### 2回目以降の起動

- `AutoTicket.exe` をダブルクリック → システムトレイに常駐
- デフォルトホットキー `Ctrl+Shift+Space` でタスク入力ウィンドウが開く
- トレイアイコンの色でバックエンド接続状態を確認できる

| アイコン色 | 状態 |
|-----------|------|
| 緑 | バックエンド接続中 |
| 黄 | 応答遅延（HuggingFace Spaces のスリープ明けなど） |
| 赤 | バックエンド未接続 |

### Windows ログイン時の自動起動（任意）

設定画面（トレイアイコン右クリック → 設定）の「Windowsログイン時に自動起動」を ON にする。

## 4. ローカル AI（Ollama）のセットアップ（任意）

Ollama がなくてもウィジェットは使える。  
「AIで起票する」ボタンを押すと AI 解析がスキップされ、タイトル空欄の確認画面が開くので手動入力する。

AI 解析を使いたい場合は以下の手順でセットアップする。

```
1. https://ollama.com/download から Ollama をインストール

2. コマンドプロンプトでモデルをダウンロード（どちらか選択）:
   ollama pull qwen2.5:1.5b      # 軽量・高速（推奨）約 1 GB
   ollama pull gemma4:e2b-q4_K_M # 高精度・量子化版   約 2 GB

3. ウィジェットの設定画面を開き「Ollama テキストモデル」ドロップダウンから
   インストールしたモデルを選択して保存する
```

> モデル名は設定画面を開いたとき自動取得される。🔄 ボタンで手動再取得も可能。

## 5. 再ビルド・再配布が必要なケース

| 変更内容 | 必要か |
|---------|--------|
| `widget/` 以下の Python コード（バグ修正・機能追加） | **必要** |
| 新しい Python ライブラリの追加 | **必要** |
| `widget/data/templates.json`（テキストテンプレート）の変更 | **必要** |
| バックエンド URL・ユーザー設定の変更 | 不要（設定画面で変更可） |
| Ollama モデル名の変更 | 不要（設定画面で変更可） |
| バックエンド（FastAPI）側のみの変更 | 不要 |

---

## 6. 再ビルド手順（担当者作業）

```powershell
# 1. プロジェクトフォルダへ移動
cd "...\AutoTicket"

# 2. ビルド（既存の dist\AutoTicket\ は自動的に上書きされる）
python -m PyInstaller AutoTicket.spec --noconfirm

# 3. dist\AutoTicket\ フォルダを共有フォルダに上書きコピー
```

> `dist\AutoTicket\` が開かれていると上書きに失敗することがある。  
> その場合は一度フォルダを閉じてから再実行する。

ビルド所要時間の目安: **約 2〜3 分**  
生成物のサイズ: **約 494 MB**（faster-whisper・scipy を含むため大きめ）

## 7. トラブルシューティング

| 症状 | 対処 |
|------|------|
| 起動しても画面が出ない | `widget\widget_error.log` を確認する |
| トレイアイコンが赤のまま | 設定画面でバックエンド URL を確認、または HuggingFace Spaces が起動するまで待つ |
| 「AIで起票する」が毎回空欄になる | Ollama が未起動。タスクマネージャーで `ollama.exe` が動いているか確認する |
| ウィザードが毎回出る | `config.json` の `first_run_complete` が `false` のまま。ウィザードを最後まで完了させる |
