## 検出された問題・懸念事項

### 🔴 High: タスク削除機能が未実装
- タスク詳細ページに削除ボタンが存在しない
- **対応推奨**: タスク詳細ページにステータス「キャンセル」変更 or 削除ボタン追加

### 🟡 Medium: シードデータの重複表示
- タスク一覧・カンバン・スケジュール等で全タスクが2件ずつ重複表示
- 原因: `seed_dummy_data.py` が複数回実行された可能性
- **対応**: DBリセット後に `seed_dummy_data.py` を1回だけ実行

```bash
# PostgreSQL の場合
psql -U postgres -d autoticket -c "TRUNCATE TABLE tasks, projects, user_profiles CASCADE;"
python scripts/seed_dummy_data.py
```

### 🟡 Medium: シナリオ5・7 未確認
- 今回の自動テストでは未実施

### 🟢 Low: Ant Design 非推奨 API 警告 (コンソールエラー3件)
- `Space[direction]` → `orientation`
- `Statistic[valueStyle]` → `styles.content`
- `List` コンポーネント次バージョン廃止予定

## 未テストシナリオの手動確認手順

### シナリオ5: 二重登録防止
1. DEV ログインで梅本 美結 を選択
2. タスク一覧で「新規タスク」→ 既存と同一タイトルで登録
3. 同一タイトルの登録が許可されるか確認 (タイトル重複はOK、外部IDの重複のみ制御)
4. Planner ポーリング時の重複は `data/processed.db` の `processed_id` で制御済み

### シナリオ7: 個人ToDo・visibility制御
1. DEV ログインで寄田 俊雄 (member/人事) を選択
2. 「新規タスク」→ 公開範囲=「自分のみ」で作成して保存
3. ログアウト→梅本 美結 (member/総務) でログイン
4. 寄田の「自分のみ」タスクが梅本の一覧に**表示されない**ことを確認
5. タスク一覧の「自分のToDoのみ」スイッチ ON で自分のタスクのみ絞り込まれることを確認
