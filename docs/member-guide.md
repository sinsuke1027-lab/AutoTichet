# AutoTicket メンバー向けガイド

**対象**: AutoTicket を初めて使うメンバー  
**所要時間**: 初回セットアップ 約5分 / 通常利用 数秒〜

---

## このツールでできること

AutoTicket は2つの使い方があります。

| 使い方 | 説明 |
|--------|------|
| **ウィジェット**（デスクトップアプリ） | キーボードショートカットで素早くタスクを起票。AIが文章から自動でタスク情報を入力してくれる |
| **Web アプリ**（ブラウザ） | タスク一覧・ガントチャート・ワークロードなど詳細な管理画面 |

---

## Part 1: ウィジェット（デスクトップアプリ）のセットアップ

### 手順 1: アプリをPCにコピーする

1. 担当者から共有された `AutoTicket` フォルダを受け取る
2. フォルダごと、自分のPCの好きな場所にコピーする（例: `Cドライブ` > `Tools` > `AutoTicket`）
3. `_internal` フォルダと `AutoTicket.exe` が **同じフォルダ内** にあることを確認する

> ⚠️ `AutoTicket.exe` だけを別の場所に移動すると起動しなくなります。フォルダごと移動してください。

### 手順 2: 初回起動（セットアップウィザード）

1. `AutoTicket.exe` を **ダブルクリック** して起動する
2. Windowsのセキュリティ警告が出た場合は「詳細情報」→「実行」をクリック
3. セットアップウィザードが開く（3ステップ）

**Step 1: バックエンドURL の入力**

入力欄に以下のURLをそのまま貼り付けて「接続テスト」ボタンをクリックします。

```
https://shinsukei-autotichet.hf.space
```

「✅ 接続成功」と表示されたら「次へ」をクリックします。

> ⚠️ 「接続失敗」と表示された場合: サーバーが起動中です。1〜2分待ってから再度「接続テスト」をクリックしてください。

**Step 2: 自分の名前を選択**

ドロップダウンリストから自分の名前を選んで「次へ」をクリックします。

**Step 3: 確認して起動**

設定内容を確認し「起動する」をクリックします。

### 手順 3: 通常の使い方

セットアップ完了後、アプリはタスクバーの右下（通知領域）にアイコンが表示されます。

| アイコンの色 | 状態 |
|------------|------|
| 🟢 緑 | 正常（サーバー接続中） |
| 🟡 黄 | 接続中（しばらく待つ） |
| 🔴 赤 | 接続失敗（URLを確認） |

#### タスクを起票する

キーボードで **`Ctrl + Shift + Space`** を押すと入力ウィンドウが開きます。

**AI で起票する場合:**
1. テキスト欄にタスク内容を自由に入力（例:「来週月曜までに田中さんへ見積書を送る」）
2. 「AI で起票する」ボタンをクリック
3. AIがタイトル・期日・担当者などを自動で入力してくれる
4. 内容を確認して「起票」ボタンをクリック

**手動で起票する場合:**
1. 「手動で起票する」ボタンをクリック
2. タイトル・期日・担当者などを直接入力
3. 「起票」ボタンをクリック

#### 今日のタスクを確認する

トレイアイコンを右クリック → **「今日のタスク」** を選ぶと、今日期限のタスク一覧が表示されます。

完了したタスクは「✅ 完了」ボタンをクリックすると完了記録できます（実績工数も入力できます）。

### Windowsログイン時に自動起動する（推奨）

毎回 exe を探す手間を省けます。

1. トレイアイコンを右クリック → **「設定」** を開く
2. 「Windows ログイン時に自動起動」の **トグルをON** にする
3. 「保存」をクリック

次回 PC 起動時から自動的に AutoTicket が起動します。

## Part 2: Web アプリのアクセス方法

ブラウザで以下のURLを開きます（ブックマーク推奨）。

```
https://auto-tichet.vercel.app/
```

### ログイン方法

1. ブラウザで上記URLを開く
2. 「開発用ログイン」画面が表示される
3. **自分の名前のカード** をクリックする

> ログイン後、画面右上に `[DEV] 自分の名前` と表示されれば成功です。

### 主な画面の説明

| メニュー | 使い方 |
|---------|--------|
| ダッシュボード | 全体のタスク状況・KPIをひと目で確認 |
| タスク一覧 | タスクの検索・フィルタ・新規作成 |
| カンバン | ステータス別のボード表示 |
| ガント | スケジュール・依存関係の可視化 |
| ワークロード | メンバーごとの作業量確認 |
| マイページ | 自分のタスクと工数サマリー |
| データインポート | 他システムからのタスク一括取込み |

## トラブルシューティング

| 症状 | 対処方法 |
|------|---------|
| ウィジェットが起動しない | `AutoTicket.exe` と `_internal` フォルダが同じ場所にあるか確認 |
| 「接続失敗」のまま | 1〜2分待ってから再試行。それでも失敗なら担当者に連絡 |
| 名前がリストに出ない | 担当者にユーザー登録を依頼 |
| ウィザードが毎回出る | ウィザードを最後まで「起動する」まで完了させる |
| Web アプリが開かない | インターネット接続を確認。VPN が必要な場合は接続する |
| ログイン後に自分の名前がない | 担当者にユーザー登録を依頼 |
