# AutoTicket — 要件定義書

最終更新: 2026-05-18
版数: Ver.1.0（37機能 統合版）
ステータス: 確定

---

## 1. プロジェクト目的

「入力負荷を最小化し、チームと個人の仕事を可視化する」

- メール・会議・チャット等からの **AI 自動起票** で入力なしにタスクが生まれる環境の構築
- ダッシュボード・ワークロード可視化による **今日やること・誰が忙しいかの即時把握**
- ガント/カンバン/カレンダーの **柔軟なビュー切り替え** でプロジェクト管理と個人管理を統合

---

## 2. 対象範囲

### 対象業務
プロジェクト業務の進行管理 / 個人 ToDo 管理 / 問い合わせ・会議起点のタスク管理 / 定型業務の自動生成 / ワークロード可視化

### 対象ユーザー
一般メンバー / チームリーダー / プロジェクトマネージャー / システム管理者

### **対象外**（スコープ外）
- モバイル専用アプリ（PC ブラウザ対応に注力。レスポンシブ対応は実施）
- タスク管理内でのチャット機能（Teams を継続利用）
- 会計・購買・勤怠等の基幹システム連携

---

## 4. 非機能要件

| ID | カテゴリ | 要件 |
|----|--------|------|
| NFR-01 | セキュリティ | 機密データ（Pattern B）を外部 LLM（OpenAI 等）へ一切送信しない |
| NFR-02 | 認証・認可 | Entra ID（MSAL）でログインし、ロールに基づくアクセス制御を実施 |
| NFR-03 | 操作性 | 初見で直感的に利用でき、D&D やビュー切り替えがシームレスであること |
| NFR-04 | 性能 | ダッシュボード・カンバン等の主要画面が 3 秒以内にレンダリングされること |
| NFR-05 | 型安全 | Python: mypy --strict。TypeScript: strict モード |
| NFR-06 | データモデル | Pydantic v2 のみ使用。生の dict をビジネスロジック間で引き回さない |
| NFR-07 | 非同期処理 | ファイル I/O・ネットワーク I/O・DB 操作はすべて async/await で実装 |
| NFR-08 | 監査ログ | 全 LLM 呼び出し・信頼スコア・起票結果を Langfuse に記録 |
| NFR-09 | コード品質 | ruff check・ruff format（バック）/ ESLint・Prettier（フロント）|
| NFR-10 | テスト | pytest（バック）/ Vitest + Testing Library（フロント）|
| NFR-11 | DB マイグレーション | Alembic で管理。ダウンタイムなしのスキーマ変更を基本とする |
| NFR-12 | レスポンシブ | PC ブラウザ（1280px 以上）を主対象。スマートフォン専用アプリは対象外 |
| NFR-13 | 拡張性 | 将来の AI 機能追加・他 SaaS API 連携が容易なアーキテクチャ |

## 5. 制約条件

| 項目 | 内容 |
|------|------|
| OS | Windows 11 Pro（会社支給 PC） |
| Python | 3.11 以上 |
| M365 ライセンス | Power Automate Standard（HTTP コネクタ使用不可）|
| Azure サブスク | なし（M365 テナントの Entra ID のみ利用可）|
| データ保管 | M365 テナント内またはローカルのみ（外部クラウドストレージ禁止）|
| LLM 外部送信 | Pattern B（機密）データの外部 LLM 送信禁止 |
| 認証方式 | Entra ID（MSAL）を使用。ユーザー委任権限（Authorization Code Flow）|

## 6. フェーズ構成

### Phase 1（Must）— 基盤構築と「二重入力・見えない」の解消

対象機能: F-01〜06, F-08〜13, F-16〜19, F-21

主な成果物:
- タスクの手動登録・一覧・詳細管理 UI
- ダッシュボード（今日やること・ワークロード・各種指標）
- AI 自動起票パイプライン（メール・議事録・Forms）
- Teams 通知・コメント・メンション
- Entra ID 認証・ロール制御

### Phase 2（Should）— UI/UX 向上と起票の完全自動化

対象機能: F-07, F-14〜15, F-22〜32, F-36

主な成果物:
- マルチビュー（ガント/カンバン/カレンダー）＋ 依存関係
- あらゆる入り口からの起票（右クリック・ボット・スクショ・フォーム拡充）
- AI 補助機能（要件明確化・遅延予測・棚卸し・サブタスク）
- 工数自動最適化・テンプレート・リスケジュール

### Phase 3（Could）— 自律的タスク管理の実現

対象機能: F-20, F-33〜35, F-37

主な成果物:
- 会議音声リアルタイム起票
- AI 高度化（最適アサイン・引き継ぎ自動生成）
- マイルストーン高度管理
- ペアワークモード（リアルタイム共同編集）

## 7. ユースケース概要

```
UC-01: メール・議事録からの自動起票（✅ 実装済み）
  手順: APScheduler → Graph API ポーリング → LangGraph エージェント
        → 信頼スコア判定 → PostgreSQL 保存 / Teams 承認依頼

UC-02: Microsoft Forms からの自動起票（Phase 1）
  手順: Forms 回答 → SharePoint リスト蓄積
        → Graph API ポーリング → LangGraph エージェント → PostgreSQL 保存

UC-03: ダッシュボード閲覧（Phase 1）
  手順: ユーザーが React SPA にアクセス → Entra ID 認証
        → GET /api/v1/dashboard/summary → チャート表示

UC-04: タスク手動登録（Phase 1）
  手順: タスクフォーム入力 → 類似タスク警告チェック（F-04）
        → POST /api/v1/tasks → Teams 通知（担当者へ）

UC-05: ガントビューでの依存関係管理（Phase 2）
  手順: プロジェクト詳細 → ガントビュー切替
        → D&D でタスク日程調整 → 依存タスクを自動リスケジュール
```
