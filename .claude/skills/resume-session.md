# セッション再開スキル

このスキルが呼ばれたら以下を順番に実行する。

## 手順

1. `docs/progress.md` を読んで現在のフェーズ・完了済み作業・ブロッカーを把握する
2. `docs/tasks.md` を読んで次の未完了タスクを特定する
3. ユーザーに以下の形式で報告する：

```
## 前回の続き

**現在のフェーズ**: Phase X — XXXXX
**最終更新日**: YYYY-MM-DD
**完了した作業**: XXXXX
**次のアクション**: XXXXX
**ブロッカー**: XXXXX（なければ「なし」）

続きから進めてよいですか？
```

4. ユーザーの確認後、次のタスクに取りかかる

## トリガーワード
「続きから」「resume」「前回の続き」「進捗確認」
